# Examples

This section provides practical examples of how to use Ceeblue Video.js Plugin in different scenarios.

## Available Examples

- [Simple player](/examples/simple) - Basic setup with fallback between Ceeblue protocols

The repository `examples/` directory also includes:

- `player.html` for the advanced fallback and DRM demo
- `webrtc-player.html` for a direct WebRTC source example
- `wrts-player.html` for a direct WRTS source example

## Running Examples Locally

To run these examples locally:

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run docs:dev
   ```
4. Navigate to the examples section in the documentation

The source files for the browser demos live in the repository `examples/` directory, with the advanced demo implemented in `examples/player.html`.
